# 🌍 Global Fertility and Population Analysis (Tableau Project)

This project presents a comprehensive Tableau-based analysis of global fertility rates and population distribution using United Nations datasets (1950–2024). It visualizes demographic trends across major countries and highlights key insights into socio-economic influences on fertility.

## 📁 Files
- `582 Goup Project.twbx` — Tableau workbook containing interactive dashboards
- `Group Project ppt presentation.pptx` — Final presentation summarizing key findings

## 📊 Key Features
- Fertility rate comparison across countries and continents
- Historical trends from 1960–2023
- Insights into development, healthcare, and education impacts on fertility
- Regional population dominance (India, China, USA)

## 📌 Tools Used
- Tableau
- PowerPoint
- United Nations open data
